Spekin: gaps canvas, the screens the PRD asks for that nothing draws yet

The main canvas covers 15 boards and every one of their 314 feature cells is now built and proven in the app. This second canvas draws what is still missing: the PRD v0.2.3 requirements that no board and no screen covers. The list comes from the IMP-52 classification of the 80 unmapped requirements (24 Nov 2026): 38 are real gaps. 29 of them become screens on 13 boards here; 9 are engineering rules listed on G00 for task cards. Same look, kit and sample project (Meranti Yard) as the main canvas.

How this canvas was made
Classification: docs/handoff/req-map-2026-11-24.md, 80 rows: 2 map, 13 core, 27 later, 38 gap.Plan: docs/design/spekin-canvas/gaps-plan.mjs. The build fails if a gap is on no board or on two.Boards use the PRD's own screen codes and new feature IDs from F401.The 27 "later" rows (deferred by the PRD) and 13 "core" rows are not drawn here; they need an owner decision or a test, not a screen.
How to read a board
Same as the main canvas: yellow outline = NEW, navy note = behaviour, state buttons switch real states, every control says what it does, LATER marks a future control.Each board's Stories card names the PRD requirement IDs it answers.
