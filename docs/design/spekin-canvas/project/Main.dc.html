Spekin: design canvas for review before build

Browser-first workspace that takes an idea through eight stages, from Planning to Deployment, with a living spec, an infinite canvas and contextual chat. Drawn after OpenDesign (the main reference), with Paraframe, Onlook and Momo as pattern references. Every board shows the new design only. All data is one fictional sample project, Meranti Yard.

How to read a board
yellow outline = NEW. Spekin has nothing like it yet.amber dashed = PARTIAL, with Exists and Missing.navy note = behaviour a still picture cannot show.State buttons (top right of a board) switch real states. Each state names its Entry click path and its Data record.Every control carries what it does; LATER marks a control shown only as future.
