# 0006. License the repository under Apache-2.0

Status: accepted, 23 Nov 2026 (owner)

## Context

The owner wants everyone to be able to build Spekin together. The main reference products we may reuse are also Apache-2.0.

## Decision

The repository is Apache-2.0 (LICENSE, NOTICE). Contributions are accepted under its section 5. Copyright line: "The Spekin Authors".

## Consequences

Anyone may use, change and redistribute Spekin, keeping the notices. Publishing the repository (making it public) is a separate owner decision. See docs/DECISIONS.md.
