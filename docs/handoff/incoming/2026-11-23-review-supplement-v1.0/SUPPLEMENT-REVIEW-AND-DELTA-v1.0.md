### Optional concept—not an accepted new feature

Job: an engineer reviewing a selected requirement understands **which responsibility owns it, which contract/state changes, why that choice was made, and what test/evidence proves it** without reading an entire generated codebase.

First-value path, if approved: open an existing architecture/contract artifact in Backend (also linked from Design/Integration) → select a logical component in the flat view → see its responsibility and versioned interface/state/tradeoff → follow requirement/task/test/evidence links → return with selection and viewport intact.
