HOW TO READ A BOARD
yellow outline = NEW. Spekin has nothing like it yet.
amber dashed = PARTIAL, with Exists and Missing.
navy note = behaviour a still picture cannot show.
State buttons (top right of a board) switch real states. Each state names its Entry click path and its Data record.
Every control carries what it does; LATER marks a control shown only as future.
